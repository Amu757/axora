Axora Solutions – React Frontend Website

Axora Solutions is a modern BPO (Business Process Outsourcing) company website built with React.
This project showcases company services, expertise, and contact details in a professional layout with responsive design.

🚀 Features

⚡ React Frontend – Built with React and React Router DOM

📱 Responsive Design – Fully mobile-friendly UI

🎨 Custom Components – Navbar, Footer, Service Cards, Contact Page, etc.

🖼️ Image + Text Sections – Alternating layout for "Why Choose Us"

🔝 Auto Scroll to Top – Smooth page navigation experience

🔗 React Router Integration – Seamless navigation without reloads

🧩 Reusable UI Components – Easy to maintain and expand

📂 Project Structure
axora-solutions-frontend/
│── public/              # Static files (logo, banner images, etc.)
│── src/
│   ├── components/      # Navbar, Footer, ScrollToTop, etc.
│   ├── pages/           # Home, Services, About, Contact
│   ├── App.js           # Main App with Routes
│   ├── index.js         # React entry point
│── package.json         # Dependencies & scripts
│── README.md            # Project documentation

⚙️ Installation & Setup

Clone the Repository

git clone https://github.com/Amu757/axora
cd axora-solutions-frontend


Install Dependencies

npm install


Start Development Server

npm start


Build for Production

npm run build

🛠️ Tech Stack

React.js – UI Library

React Router DOM – Page navigation

CSS3 / Flexbox / Grid – Styling

Node.js + NPM – Package management
